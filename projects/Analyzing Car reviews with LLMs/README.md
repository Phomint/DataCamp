# Analyzing Car Reviews with LLMs

Projeto prático de análise de sentimentos e extração de informações de avaliações de carros utilizando modelos de linguagem de grande porte (LLMs).

## Conteúdo

- **notebook.ipynb** — Implementação do pipeline de análise das avaliações.
- **data/** — Diretório contendo os datasets necessários:
    - `car_reviews.csv`: Conjunto de dados com as avaliações dos usuários.
    - `reference_translations.txt`: Arquivo de referência para validação de tarefas de tradução ou resumo.
