## 📖 Lições

Confira os detalhes de cada módulo:

- [**Explainability Metrics**](./lessons/Explainability%20Metrics/README.md) — Técnicas de explicabilidade (LIME, Consistency, Chat-based models).
- [**Intermediate Deep Learning with PyTorch**](./lessons/Intermediate%20Deep%20Learning%20with%20PyTorch/README.md) — OOP, CNNs, RNNs, LSTMs e modelos multi-input/output.
- [**Introduction to Spark SQL in Python**](./lessons/Introduction%20to%20Spark%20SQL%20in%20Python/README.md) — Boas práticas de logging e debugging com Spark.
- [**LLMs in Python**](./lessons/LLMs%20in%20Python/README.md) — Uso de LLMs, fine-tuning e métricas de avaliação (BLEU, ROUGE).
- [**MLOps Concepts**](./lessons/MLOps%20Concepts/README.md) — Ciclo de vida de modelos, deployment, monitoramento e maturidade.
- [**Responsible AI Data Management**](./lessons/Responsible%20AI%20Data%20Management/README.md) — Ética, viés e transparência em sistemas de IA.
- [**Working with Llama3**](./lessons/Working%20with%20Llama3/README.md) — Práticas com Llama 3, papéis de chat e saídas estruturadas.

## 🛠️ Tecnologias Utilizadas

- **Python** — Linguagem principal das lições e projetos
- **R** — Utilizado no projeto do Dr. Semmelweis
- **PyTorch** — Framework principal de deep learning
- **Apache Spark** — Processamento de dados em larga escala
- **LIME** — Explicabilidade local de modelos
- **tidyverse / ggplot2** — Manipulação e visualização de dados em R
- **Jupyter Notebooks** — Ambiente interativo de desenvolvimento

---

## 🎯 Objetivo

Este repositório documenta o progresso de estudos na plataforma **DataCamp**, cobrindo tópicos de:

- Análise exploratória de dados
- Deep Learning (CNNs, RNNs, LSTMs, GRUs)
- Modelos multi-input e multi-output
- Explicabilidade de modelos de ML/AI
- Engenharia de dados com Spark
- Automação de OCR e digitalização de documentos
