# LLMs in Python

Este diretório contém lições sobre o uso de Large Language Models (LLMs) em Python, cobrindo desde a introdução até o ajuste fino (fine-tuning) e avaliação.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| **1. Introduction to LLMs in Python.ipynb** | Introdução aos conceitos básicos de LLMs. |
| **2. Using pre-trained LLMs.ipynb** | Como utilizar modelos pré-treinados para diversas tarefas. |
| **3. Understanding the transformer.ipynb** | Detalhes sobre a arquitetura Transformer. |
| **4. Preparing for fine-tuning.ipynb** | Preparação de datasets e ambiente para fine-tuning. |
| **5. Fine-tuning through training.ipynb** | Execução do processo de treinamento para ajuste fino. |
| **6. Fine-tuning approaches.ipynb** | Diferentes abordagens e estratégias para fine-tuning. |
| **7. The evaluate library.ipynb** | Uso da biblioteca `evaluate` da Hugging Face. |
| **8. Metrics for language tasks: perplexity and BLEU.ipynb** | Métricas de avaliação: Perplexity e BLEU. |
| **9. Metrics for language tasks: ROUGE, METEOR, EM.ipynb** | Outras métricas: ROUGE, METEOR e Exact Match (EM). |
| **10. Safeguarding LLMs.ipynb** | Técnicas de segurança e moderação em modelos de linguagem. |
| **resources.py** | Scripts auxiliares e recursos utilizados nas lições. |

## Diretórios Adicionais
- `finetuded/`: Contém checkpoints gerados durante o processo de fine-tuning.
- `my_finetuned_files/`: Contém os arquivos finais do modelo após o ajuste fino.
