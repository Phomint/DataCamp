# MLOps Concepts

Este diretório aborda os conceitos fundamentais de MLOps (Machine Learning Operations), focando na operacionalização e gestão do ciclo de vida de modelos.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| **1. Introduction.ipynb** | Introdução ao MLOps e sua importância no ciclo de vida de IA. |
| **2. Machine Learning design.ipynb** | Considerações de design para sistemas de machine learning escaláveis. |
| **3. Machine Learning development.ipynb** | Melhores práticas no desenvolvimento de modelos voltados para produção. |
| **4. Machine Learning deployment.ipynb** | Estratégias de implantação e entrega contínua. |
| **5. Monitoring machine learning models.ipynb** | Monitoramento de performance e detecção de desvios (drift). |
| **6. Retraining a machine learning model.ipynb** | Estratégias de retreinamento automático de modelos. |
| **7. Levels of MLOps maturity.ipynb** | Discussão sobre os diferentes níveis de maturidade em MLOps. |
| **8. MLOps tools.ipynb** | Visão geral das ferramentas populares no ecossistema MLOps. |
