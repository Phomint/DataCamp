# Working with Llama 3

Este diretório contém lições práticas sobre como utilizar e configurar o modelo Llama 3 para diversas tarefas de processamento de linguagem natural.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| **1. Tuning Llama 3 parameters.ipynb** | Ajuste de parâmetros de geração (temperatura, top-p, etc). |
| **2. Assigning chat roles.ipynb** | Definição de papéis (System, User, Assistant) para guiar o comportamento do modelo. |
| **3. Guiding unstructured responses.ipynb** | Técnicas para obter melhores respostas em formato de texto livre. |
| **4. Generating structured output.ipynb** | Como forçar o modelo a gerar saídas estruturadas, como JSON. |
| **5. Building conversations.ipynb** | Criação de fluxos de conversa e manutenção de contexto. |

## Recursos
- `models/`: Contém os arquivos do modelo Llama 3 em formato GGUF.
